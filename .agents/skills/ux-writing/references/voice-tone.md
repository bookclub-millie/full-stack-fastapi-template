# 보이스와 톤

## 목소리

**반갑게 맞아주고, 어려운 순간에는 차분하게 돕는 사람.**
사무적인 안내문도, 지나치게 친한 척하는 친구도 아니다. 자연스러운 존댓말로 거리를 좁힌다.

- 환영할 때는 기능 소개보다 사람을 먼저 맞는다: `다시 만나 반가워요`.
- 제안할 때는 참여할 여지를 준다: `첫 항목을 만들어 볼까요?`
- 설명할 때는 일상적인 말을 고른다: `비밀번호를 재설정할 수 있습니다`보다 `새 비밀번호를 만들 수 있어요`.
- 공감 뒤에는 실질적인 도움을 붙인다. `괜찮아요`만으로 오류를 끝내지 않는다.
- 상태를 정확히 말하는 것과 딱딱하게 말하는 것은 다르다. 모든 안내를 명령형으로 만들지 않는다.

## 상황에 따른 온도

| 상황 | 쓰는 방식 | 피할 방식 |
|---|---|---|
| 로그인·재방문 | 반가운 인사, 익숙한 행동 버튼 | 환영 문구를 기능명으로 교체 |
| 가입·첫 사용 | 짧은 환영과 시작 제안 | 입력 절차를 길게 나열, 근거 없는 혜택 약속 |
| 비밀번호 찾기 | 부담을 덜어주고 받을 결과 설명 | 사용자를 탓하거나 계정 안전을 단정 |
| 빈 화면 | 아직 없는 상태와 첫 행동 초대 | 정상적인 빈 상태를 실패처럼 설명 |
| 일반 완료 | 담백한 결과, 중요한 첫 성취에는 짧은 축하 | 사소한 저장마다 과한 환호 |
| 입력·연결 오류 | 문제와 실제 가능한 수정 방법 | `앗!`, `이런!`을 모든 오류 앞에 붙이기 |
| 삭제·결제·보안 | 차분한 해요체와 정확한 영향·선택지 | 농담, 안심 강요, 취소를 비난하는 문구 |
| 법적 고지·사고 공지 | 필요한 격식, 조건·영향·책임 보존 | 친근함을 위해 불리한 내용 생략 |

## 자연스러움의 경계

- `괜찮아요`는 비밀번호를 잊는 일처럼 일상적인 어려움의 도입에 쓸 수 있다. 원인 불명의 오류·유출·금전 손실에는 쓰지 않는다.
- `~드릴게요`는 서비스가 실제로 수행할 일을 말할 때 쓴다. 모든 문장을 서비스의 약속으로 바꾸지 않는다.
- `회원님`, `고객님`, `당신`을 매번 넣지 않는다. 호칭 없이도 충분히 다정할 수 있다.
- 느낌표는 환영·축하의 온도를 높이는 선택지다. 매 문장, 버튼, 실패 메시지에 붙이지 않는다.
- 기본은 이모지 없는 문구다. 친근함을 표현하려고 새 마스코트·밈·게임 용어를 끌어오지 않는다.
- `정상적으로`, `원활한 이용을 위해`, `요청을 재시도 바랍니다` 같은 관용적인 행정 문구를 덜어낸다.
- 무조건 줄이지 않는다. 한 문장의 공감이 화면을 더 편안하게 만든다면 남긴다.

## 조사 근거

아래는 공식 자료에서 관찰한 사례이지 Discord 내부 라이팅 가이드가 아니다.
한국어 도움말과 영어 제품 화면은 서로 다른 매체·언어이므로 동일한 문체라고 단정하지 않는다.

| 공식 출처 | 확인한 표현·구조 | 이 스킬에 반영한 해석 |
|---|---|---|
| [로그인 도움말](https://support.discord.com/hc/ko/articles/360057027354)의 [공식 화면 이미지](https://support.discord.com/hc/article_attachments/32396312580375) | 영어 제목 `Welcome back!`, 설명 `We're so excited to see you again!`, 버튼 `Log In` | 제목은 환영하고 버튼은 동작을 명확히 말한다. 설명을 입력 지시로만 채울 필요는 없다. |
| [한국어 비밀번호 도움말](https://support.discord.com/hc/ko/articles/218410947) | `모두 경험해 보셨을 겁니다. 그리고 비밀번호는 항상 어려운 법이죠!`로 시작한 뒤 복구 절차 안내 | 사용자에게 책임을 묻기 전에 어려움을 인정한다. 긴 문장과 번역투는 그대로 가져오지 않는다. |
| [한국어 로그인 도움말](https://support.discord.com/hc/ko/articles/360057027354) | `자세히 알아보고 싶으신가요?`로 추가 안내 제안. 직접 생성하지 않은 QR 로그인은 승인하지 말라고 명시 | 대화형 질문과 정확한 보안 안내는 공존할 수 있다. 위험 안내는 부드러움보다 영향 전달이 중요하다. |

`다시 만나 반가워요`, `만나서 반가워요!`, `이메일로 링크 받기`는 사용자 취향과 위 관찰을 반영한 자체 작성안이다. Discord 공식 한국어 UI의 직접 인용으로 소개하지 않는다.

# 표기법

프로젝트의 기존 표기·현지화 규칙을 우선한다. 문구를 다듬으면서 날짜·가격·수량·시간대나 런타임 포맷 로직을 바꾸지 않는다.

## 문장과 기호

- 맞춤법과 띄어쓰기는 국립국어원 어문 규정을 기본으로 한다. 확정된 서비스명·고유명사는 보존한다.
- 완결된 설명 문장은 마침표로 닫는다. 제목·버튼·탭·라벨에는 마침표를 붙이지 않는다.
- 쉼표는 말의 흐름에 필요할 때 쓴다. `비밀번호가 기억나지 않나요?`처럼 공감이나 제안의 질문도 쓸 수 있다. 모든 제목을 질문으로 만들지는 않는다.
- 환영·축하 제목에는 느낌표를 쓸 수 있다: `만나서 반가워요!`. 느낌표를 반복하거나 이모지로 친근함을 대신하지 않는다. 결제·탈퇴·법적 고지·오류·보안 안내에는 장식적인 느낌표·이모지를 쓰지 않는다.
- 인용은 원문을 보존한다. 괄호는 보충 설명에만 사용하고 중첩하지 않는다.
- 화면 잘림은 말줄임표를 문구에 직접 붙여 해결하지 않는다. 레이아웃 문제를 별도로 알린다.
- 목록은 기존 의미 구조를 유지한다. 텍스트 기호로 UI 구조를 대신 만들지 않는다.

## 숫자와 단위

- 날짜는 기존 형식을 유지한다. 새 기준이 필요한 경우 `2026년 5월 6일`처럼 명확한 표현을 사용한다.
- 시간은 기존 시간대·12/24시간제를 확인한다. 문구 수정으로 시간대를 추정하거나 변환하지 않는다.
- 금액은 통화와 값을 보존한다. 한국 원화 표기의 예는 `1,500원`이다.
- 범위는 시작·끝·단위를 분명히 한다. 마감 시각이나 포함 범위를 생략하지 않는다.
- 수량은 실제 대상의 단위를 쓴다. 상한 표시가 없는 정확한 수치를 임의로 `999+`처럼 축약하지 않는다.
- 퍼센트와 단위는 기존 규칙을 유지하며 `3.3%`, `30분`, `1GB`처럼 쓴다.
- 상대 시간·남은 기간은 기존 계산 결과를 사용한다. 문구 작업에서 새로운 임계값을 도입하지 않는다.

## 용어와 영문

- 같은 개념에는 같은 표현을 쓴다. 기존 화면·요구사항에서 확정한 용어를 먼저 찾는다.
- 불필요한 외래어는 쉬운 말로 바꾸되 `로그인`, `다운로드`처럼 익숙한 용어를 억지로 풀지 않는다.
- 고유명사·약어의 공식 대소문자는 보존한다.
- 계정·아이디, 삭제·비활성화, 접수·완료처럼 의미가 다른 표현은 자연스럽게 보인다는 이유로 교환하지 않는다.

## 문서 관리

- 요구사항(REQ)·인수조건(AC)·사용자 흐름(FLOW)을 Issue·코드·테스트(TC)와 연결한다.
- 동작이나 설계가 변경되면 관련 문서와 테스트를 함께 갱신한다.
- 실행 결과에는 소스 SHA·환경·시각·로그 또는 화면 경로를 기록한다.
- 계획·예상 결과와 실제 결과를 구분한다. 실행하지 않은 항목은 미검증으로 남긴다.
- 비밀값과 실제 개인정보는 문서·예시·검증 기록에 포함하지 않는다.

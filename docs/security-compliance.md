미실행은 미검증, 해당 없음은 사유를 기록한다. 키·토큰·비밀번호는 코드·URL·로그·문서에 노출하지 않는다. 실제 비밀 대신 환경변수 예시와 안전한 설정 방법을 적는다.

자료 권한이 적용되는 경우에는 본인 조회 성공 / 타인 요청 거부 / 자료 유출 없음 / 저장값 불변을 각각 TC와 실행 근거로 연결한다. 이는 작성 기준이며 현재 구현이나 검증 결과가 아니다.
